# Stock Portfolio Tracker — Project Statement

## Problem Statement

Managing stock holdings manually can make it difficult to track the number of shares owned, average purchase price, current portfolio value, and realized/unrealized profit or loss.

This project develops a Python-based Stock Portfolio Tracker that allows users to manage stock purchases and sales and calculate portfolio performance.

## Scope

The system supports:
- Stock ticker validation
- Buying stocks
- Selling stocks
- Maintaining portfolio holdings
- Weighted average purchase price
- Realized P&L calculation
- Unrealized P&L calculation
- Portfolio summary

## Target Users

- Students learning programming
- Beginners learning portfolio-management concepts
- Users interested in a simple stock portfolio simulation

## High-Level Features

1. Stock validation
2. Portfolio management
3. Buy transaction
4. Sell transaction
5. Realized P&L
6. Unrealized P&L
7. Input validation
8. Error handling
